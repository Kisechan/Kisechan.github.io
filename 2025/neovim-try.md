## 快捷键归纳

算是[先前笔记的部分内容](https://blog.kisechan.space/2024/linux-note/#%E8%BE%93%E5%85%A5%E6%A8%A1%E5%BC%8F)的重置。

### 模式切换

|                    快捷键                     |            功能            |
| :-------------------------------------------: | :------------------------: |
|                 <kbd>i</kbd>                  | 进入插入模式（**光标前**） |
|                 <kbd>a</kbd>                  | 进入插入模式（**光标后**） |
|                 <kbd>o</kbd>                  |       在下方新行插入       |
| <kbd>Esc</kbd> / <kbd>Ctrl</kbd>+<kbd>[</kbd> |        返回普通模式        |
|                 <kbd>v</kbd>                  |  进入可视模式（字符选择）  |
|                 <kbd>V</kbd>                  |         行选择模式         |
|         <kbd>Ctrl</kbd>+<kbd>v</kbd>          |         块选择模式         |

### 光标移动

|                           快捷键                            |             功能              |
| :---------------------------------------------------------: | :---------------------------: |
|     <kbd>h</kbd> <kbd>j</kbd> <kbd>k</kbd> <kbd>l</kbd>     |        左/下/上/右移动        |
|                 <kbd>w</kbd> / <kbd>b</kbd>                 | 跳到下一个/上一个**单词开头** |
|                        <kbd>e</kbd>                         |         跳到单词末尾          |
|                 <kbd>0</kbd> / <kbd>$</kbd>                 |           行首/行尾           |
|                <kbd>gg</kbd> / <kbd>G</kbd>                 |         文件开头/结尾         |
| <kbd>Ctrl</kbd>+<kbd>d</kbd> / <kbd>Ctrl</kbd>+<kbd>u</kbd> |         向下/上翻半页         |

### 文本编辑

|                   快捷键                    |      功能       |
| :-----------------------------------------: | :-------------: |
|                <kbd>x</kbd>                 |  删除当前字符   |
|                <kbd>dd</kbd>                |   删除当前行    |
|                <kbd>yy</kbd>                |   复制当前行    |
|         <kbd>p</kbd> / <kbd>P</kbd>         | 粘贴到光标后/前 |
| <kbd>u</kbd> / <kbd>Ctrl</kbd>+<kbd>r</kbd> |    撤销/重做    |
|                <kbd>.</kbd>                 | 重复上一次操作  |

### 窗口和标签页

|                                      快捷键                                      |        功能         |
| :------------------------------------------------------------------------------: | :-----------------: |
|                    <kbd>Ctrl</kbd>+<kbd>w</kbd> <kbd>s</kbd>                     |    水平分割窗口     |
|                    <kbd>Ctrl</kbd>+<kbd>w</kbd> <kbd>v</kbd>                     |    垂直分割窗口     |
| <kbd>Ctrl</kbd>+<kbd>w</kbd> <kbd>h</kbd>/<kbd>j</kbd>/<kbd>k</kbd>/<kbd>l</kbd> |    切换窗口方向     |
|                                <kbd>:tabnew</kbd>                                |     新建标签页      |
|                          <kbd>gt</kbd> / <kbd>gT</kbd>                           | 下一个/上一个标签页 |

### 搜索与替换

|                快捷键                |          功能           |
| :----------------------------------: | :---------------------: |
| <kbd>/</kbd>`关键词`<kbd>Enter</kbd> |        向下搜索         |
| <kbd>?</kbd>`关键词`<kbd>Enter</kbd> |        向上搜索         |
|     <kbd>n</kbd> / <kbd>N</kbd>      | 跳转到下一个/上一个匹配 |
|       <kbd>:%s/old/new/g</kbd>       |        全局替换         |

### 其他实用功能

|               快捷键                |                    功能                    |
| :---------------------------------: | :----------------------------------------: |
|    <kbd>Ctrl</kbd>+<kbd>z</kbd>     |           挂起 Neovim ，返回终端           |
|            <kbd>fg</kbd>            |               恢复挂起的任务               |
| <kbd>:!</kbd>`命令`<kbd>Enter</kbd> | 执行外部命令（如 `:!python %` 运行当前文件 |
