## 替换

之前使用的图标库提供了 CSS 链接，不过最近它的 cdn 疑似是挂掉了，国内访问本站很慢，有时候图标完全加载不出来。

于是参考了主题的文档[^1]，改为使用来自 [Iconfont](https://www.iconfont.cn/) 的图标库，它能提供免费的图标和 CSS 链接，而且是阿里云提供的，国内访问不会受阻。免费版 Fontawesome 的图标库不提供 CSS ，不适合 Fluid 懒人配置。

[^1]: https://fluid-dev.github.io/hexo-fluid-docs/icon/#%E5%86%85%E7%BD%AE%E7%A4%BE%E4%BA%A4%E5%9B%BE%E6%A0%87
