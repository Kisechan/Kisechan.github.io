Κομήτης 的历史和思维，若能成为彗星

在上大学之前，其实我一直都没有经受过“正经的”计算机和编程学习，仅仅是爱玩点游戏，才会去折腾折腾电脑罢了，也只是学了些皮毛。直到大一的 C 语言课，我才真正用手和键盘敲下并编译运行自己的第一行代码（如果之前的恶搞 Basic 程序不算的话）。

或许对于大多数身经百战、见得多了的技术宅们而言，博客算是个简单得不能再简单的东西了，就该人手一个，各自有自己的特色，夸张的动效，还有铺天盖地的插件。在大一新生自我介绍的时候，班里有个同学展示了自己做的网站，以及一些其他的项目，或许现在来看很嘉豪，但我仍然很羡慕他们可以比我更早地领会到——原来计算机、编程和做网站是如此有趣的东西，当然也仅限于这种的羡慕了，我现在也把这个网站，还有我的主页，还有其他的项目做得很好哦。

大一下学期的春天，和老朋友聊天的时候，他告诉我可以用 Hexo 和 GitHub 做一个网站，其实不难。于是我花一个晚上，在 CSDN 和各个论坛上查怎么去搭建这样的博客[1]，注册了一个自己的 GitHub 账户，学了一下 markdown 语法，跑通了 node 环境，就通过调包的方式，把这个网站搭起来了。没买域名，没买服务器就是挂在了 GitHub Page 上，域名就是 kisechan.github.io。

所以，虽然什么前端知识都不懂，也不知道 git、node、JavaScript、GitHub、jsDelivr [2]都是什么，只会写 C 语言的 Kisechan 也用 Hexo 和 Fluid 主题就这样做起来了人生中一个小项目，可以大大方方地展示给身边的人看，可以大大方方地写一些乱七八糟的东西，然后这个网站的骨架差不多就没怎么变过了。

大二上学期，在做面向对象大作业的时候，我学了学 golang，靠网页版的 DeepSeek 来做完了大作业。和 LLM 聊技术架构的时候，才第一次了解到前端三件套是个什么，Vue.js 大概是什么，好酷啊！于是寒假就在家里古法学了学 Web 技术。买了一个域名（kisechan.space，不过现在嫌弃太长，已经不用了），学了一下运维，然后把页面迁移到了 Cloudflare。

每逢期末周，我就会写一些笔记，把老师的 slides、教案和其他资料，喂给 LLM 读一遍，然后把它的输出和自己的理解复制粘贴到 markdown 文档里，做一些整理，所以这里大部分的东西其实都是这种没什么意义的笔记。

于是后面有些想法了，还有一些日常生活，也就会写下来，做了一个工作流，可以很简便地把内容部署到云端。

有一次和母亲聊到过去的不开心的事情，于是也给她看了看博客上的日常文章，让她也理解我每天的想法。比起内容，她说的第一句话其实是——不希望我把内心里的东西写到网上，不要让自己心里的东西让别人知道。倒也算是中国家长，或者是所有中国人、乃至东亚人共有的本能，谨言慎行，生怕招惹是非。

世界的忌讳太多，人心中的礼节太多，但那又怎么样呢？不让别人知道真实的我，那我还是我吗，我又怎么知道真实的我是什么样子的呢。如果要让特定的人（或许包括你哦）喜欢我的话，那首先当然是把完整的“我”给展现出来。我就是我呀，我是天才，虽然不一定，一定不会是世界的中心，但我也是一个非常特别的存在，所以我要尽可能把我的电波传播出去。

——像彗星（κομήτης）一样。自由地在宇宙中运动，在近日点反射极大的光。
