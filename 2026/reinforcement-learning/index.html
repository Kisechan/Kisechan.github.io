强化学习概述：复习一些经典算法

本文最后更新于 2026-11-14T19:23:38+08:00

决策和交互

强化学习的经典决策环境模型是一个 Markov 决策过程（MDP, Markov Decision Process），通常表示为：

M=(S,A,P,R,γ)\mathcal M=(\mathcal S,\mathcal A,P,R,\gamma)M=(S,A,P,R,γ)

其实就是状态和转移，强化学习的最基本状态交互循环，符号可以用下面的方式理解：

符号理解
S\mathcal SS所有可能的状态
A\mathcal AA所有可以执行的动作
P(s′∣s,a)P(s'|s,a)P(s′∣s,a)在状态 sss，执行动作 aaa 后到达新状态 s′s's′ 的概率
R(s,a,s′)R(s,a,s')R(s,a,s′)从状态 sss 到 s′s's′，执行动作 aaa 所获得的奖励
γ\gammaγ对未来奖励的折扣程度

下面讲到的所有东西，都只和动作、状态、奖励有关。

动作状态和奖励

Agent 每走一步得到的 reward，真的就代表这一步有多好吗？当然不是，所以需要计算长期收益 return，表示从当前时刻开始，未来所有奖励的折扣累计值：

Gt=rt+γrt+1+γ2rt+2+⋯=∑k=0∞γkrt+kwhere γ∈[0,1]\begin{align*} G_t&=r_t+\gamma r_{t+1} +\gamma^2r_{t+2}+\cdots\\ &= \boxed{ \sum_{k=0}^{\infty}\gamma^k r_{t+k} }\quad \text{where } \gamma \in [0,1] \end{align*}Gt​​=rt​+γrt+1​+γ2rt+2​+⋯=k=0∑∞​γkrt+k​​where γ∈[0,1]​

  • γ=0\gamma=0γ=0：只考虑当前奖励。
  • γ→1\gamma\to1γ→1 ：更加重视长期收益。
  • γ→0\gamma\to0γ→0 ：更加重视短期收益。

强化学习的核心目标就是寻找一种策略 π\piπ（是一个条件概率函数，而不是一个具体的值），让期望累计 GtG_tGt​ 最大。其中，E\mathbb EE 表示数学期望，∗*∗ 一般表示“最优的”策略，arg⁡max⁡\arg\maxargmax 的意思是“找出让后面这个式子取得最大值时的那个输入参数（在这里参数就是策略 π\piπ）”。

π∗=arg⁡max⁡πEπ[Gt]{ \pi^*=\arg\max_\pi \mathbb E_\pi[G_t] }π∗=argπmax​Eπ​[Gt​]

既然我们关心长期收益，就需要一个方法预测未来能够获得多少奖励。所以可以定义一个 Value 函数，表示假设智能体现在处于状态 sss，接下来一直按照策略 π\piπ 行动，那么未来平均能够获得多少累计奖励。就是当前所处的状态整体上看有多好。

Vπ(s)=Eπ[Gt∣st=s]{ V^\pi(\textcolor{red}{s})= \mathbb E_\pi[G_t|\textcolor{red}{s_t=s}] }Vπ(s)=Eπ​[Gt​∣st​=s]

我们希望知道每一个动作分别有多好，也可以定义：

Qπ(s,a)=Eπ[Gt∣st=s,at=a]{ Q^\pi(\textcolor{red}{s,a})= \mathbb E_\pi[G_t|\textcolor{red}{s_t=s,a_t=a}] }Qπ(s,a)=Eπ​[Gt​∣st​=s,at​=a]

表示在状态 sss 下，先执行动作 aaa，然后继续按照策略 π\piπ 行动，最终能够获得多少累计奖励。

VVV 和 QQQ 存在关系：

Vπ(s)=∑aπ(a∣s)⏟当智能体处于状态 s 时，采取动作 a 的概率Qπ(s,a)V^\pi(s) = \sum_a \underbrace{ \pi(a|s) }_{ \mathclap{\text{当智能体处于状态 } s \text{ 时，采取动作 } a \text{ 的概率}} } Q^\pi(s,a)Vπ(s)=a∑​当智能体处于状态 s 时，采取动作 a 的概率π(a∣s)​​Qπ(s,a)

Bellman Equation

Return 可以拆成两部分：

Gt=rt⏟当前的奖励+γGt+1G_t=\underbrace{r_t}_\text{当前的奖励}+\gamma G_{t+1}Gt​=当前的奖励rt​​​+γGt+1​

当前的累计收益 = 当前奖励 + 折扣后的未来累计收益。因此有 Bellman Expectation Equation，其中 $a\sim \pi $ 表示 aaa 服从 π\piπ 分布，也就是从其中取出来的：

Vπ(s)=Ea∼π[r+γVπ(s′)]Qπ(s,a)=E[r+γEa′∼πQπ(s′,a′)]\begin{align*} V^\pi(s)&= \mathbb E_{a\sim\pi} \left[ r+\gamma V^\pi(s') \right] \\ Q^\pi(s,a)&= \mathbb E \left[ r+\gamma \mathbb E_{a'\sim\pi} Q^\pi(s',a') \right] \end{align*}Vπ(s)Qπ(s,a)​=Ea∼π​[r+γVπ(s′)]=E[r+γEa′∼π​Qπ(s′,a′)]​

更详细的推导可以看一看 Candlest 老师写的文章，写得很透彻：

从高中数学到 MDPhttps://blog.candlest.cc/archives/1027

DQN

根据 Bellman Expectation Equation，我们可以找到最优 Q Function，也就是 Bellman Optimality Equation：

Q∗(s,a)=E[r+γmax⁡a′Q∗(s′,a′)]{ Q^*(s,a)= \mathbb E \left[ r+\gamma\max_{a'}Q^*(s',a') \right] }Q∗(s,a)=E[r+γa′max​Q∗(s′,a′)]

DQN 全称 Deep Q-Network，它的思路很简单，也就是使用神经网络拟合 Q Function，让网络学会预测每个动作的长期收益。

假设一个 agent 有nnn 个离散动作，输入当前状态 sts_tst​，要神经网络 θ\thetaθ 输出 $ Q_\theta(s_t)= [Q_1,Q_2,\ldots,Q_n] $，选择 QQQ 最大的那个动作就可以了。但是网络本身并不知道 QQQ 应该是多少，它需要通过环境交互得到的 reward，不断调整参数，让预测的 QQQ 越来越准确。

DQN 是怎么利用 reward 的

对于当前状态 sts_tst​ 和动作 ata_tat​，我们知道：

  • 当前获得的奖励 rtr_trt​。
  • 执行动作后到达的新状态 st+1s_{t+1}st+1​。
  • 下一状态下能够选择的动作。

因此，我们可以构造一个目标值 yty_tyt​，这个在强化学习里面叫做 TD (Temporal-Difference) Target：

yt=rt+γmax⁡a′Qθ−(st+1,a′)y_t= r_t+ \gamma\max_{a'} Q_{\theta^-}(s_{t+1},a')yt​=rt​+γa′max​Qθ−​(st+1​,a′)

其中：

  • rtr_trt​：环境给出的即时奖励。
  • γ\gammaγ：折扣因子。
  • Qθ−Q_{\theta^-}Qθ−​：Target Network 预测的下一状态 QQQ Value。
  • max⁡a′\max_{a'}maxa′​：假设下一步选择价值最高的动作。
  • 如果当前状态已经终止，则 yt=rty_t=r_tyt​=rt​，因为终止状态之后没有未来奖励。

那我们已经有了预测值和目标值，接下来就可以使用均方误差构造 Loss，梯度下降优化这个函数就好了。

L(θ)=E[(yt−Qθ(st,at))2]{ L(\theta)= \mathbb E \left[ (y_t-Q_\theta(s_t,a_t))^2 \right] }L(θ)=E[(yt​−Qθ​(st​,at​))2]

Policy

Agent 连续向右走了 100 步，这 100 条数据高度相关，训练数据的分布也会非常集中。神经网络可能过度适应最近的经验，训练稳定性较差。因此 DQN 引入了 Experience Replay。

每次与环境交互，保存一定的信息，形成一个经验池（buffer），进行 random sampling，每次从历史经验中随机抽取 batch。这样一批训练数据可以包含不同时间、不同状态下的经验。

(st,at,rt,st+1,done)(s_t,a_t,r_t,s_{t+1},\text{done})(st​,at​,rt​,st+1​,done)

Replay Buffer 带来两个主要好处：

  1. 降低连续经验之间的相关性。
  2. 重复利用历史经验，提高数据利用率。

这也引出了一个重要概念：DQN 是一个 Off-Policy 算法，它可以利用旧策略甚至其他行为策略产生的经验来训练当前 QQQ Network。

Target network

还有一个问题，我们前面的目标值：

yt=rt+γmax⁡a′Qθ(st+1,a′)y_t=r_t+\gamma\max_{a'}Q_{\theta}(s_{t+1},a')yt​=rt​+γa′max​Qθ​(st+1​,a′)

如果目标值和预测值都使用同一个网络，那么每次更新参数，目标值也会跟着变化。这会导致训练目标不断移动，影响稳定性。

所以 DQN 引入两个网络：

网络作用
Policy Network负责当前 Q Value 预测
Target Network负责计算 TD Target

Target Network 使用相对稳定的参数 θ−\theta^-θ−，定期将 Policy Network 的参数 θ\thetaθ 复制过去，或者是使用软更新：

θ−←τθ+(1−τ)θ−\theta^-\leftarrow \tau\theta+(1-\tau)\theta^-θ−←τθ+(1−τ)θ−

这使得 TD Target 的变化更加平缓。

PPO

DQN 学习 Q Value，然后根据 Q Value 选择动作。

PPO 采取另一种思路，直接训练一个神经网络，让它学习在不同状态下应该以多大概率选择各个动作。

Actor

PPO 使用一个 Policy Network，也叫 Actor。Actor 输入 sts_tst​，输出 ${ \pi_\theta(a|s) } $，也就是给定状态 sss，选择动作 aaa 的概率。通常是用 softmax 处理然后输出的。

Critic

Actor 可以输出动作概率，那应该怎么知道某个动作究竟好不好呢？因此，我们需要一个基准，就是 Critic。它预测当前状态的期望累计收益，学习：

Vϕ(s){ V_\phi(s) }Vϕ​(s)

Advantage

现在我们有环境实际给出的 reward 和 Critic 预测的 value。我们就可以比较实际结果和预期结果。

首先定义 TD Error：

δt=rt+γVϕ(st+1)−Vϕ(st){ \delta_t= r_t+\gamma V_\phi(s_{t+1})-V_\phi(s_t) }δt​=rt​+γVϕ​(st+1​)−Vϕ​(st​)

计算实际得到的即时奖励，加上下一状态的估计价值，减去当前状态的估计价值。也就是单次动作实际结果和 Critic 的预期的差值。

但这个就是一步的动作差值，为了考虑连续多步的结果，PPO 使用 GAE（Generalized Advantage Estimation），定义一个 advantage A(s,a)=Q(s,a)−V(s)A(s,a)=Q(s,a)-V(s)A(s,a)=Q(s,a)−V(s)​，表示某个动作的价值，比当前状态的平均价值高出多少。这就是 PPO 更新 Actor 的重要依据。

  • Advantage 为正：倾向于提高这个动作的概率。
  • Advantage 为负：倾向于降低这个动作的概率。

At=δt+γλδt+1+(γλ)2δt+2+⋯=δt+γλAt+1\begin{align*} A_t&= \delta_t+ \gamma\lambda\delta_{t+1} +(\gamma\lambda)^2\delta_{t+2} +\cdots \\ &= \delta_t+\gamma\lambda A_{t+1} \end{align*}At​​=δt​+γλδt+1​+(γλ)2δt+2​+⋯=δt​+γλAt+1​​

其中：

  • γ\gammaγ：折扣因子。
  • λ\lambdaλ：GAE 参数。

λ\lambdaλ 控制我们如何综合不同时间跨度的 TD Error。

  • λ=0\lambda=0λ=0：只使用单步 TD Error。
  • λ→1\lambda\to1λ→1：综合更多未来 TD Error。

因此，GAE 能够在估计偏差和方差之间进行折中。

Actor 的 Loss

我们希望提高高 Advantage 动作的概率，降低低 Advantage 动作的概率，所以最直接的目标可以写成：

J(θ)=E[log⁡πθ(at∣st)At]J(\theta)= \mathbb E \left[ \log\pi_\theta(a_t|s_t)A_t \right]J(θ)=E[logπθ​(at​∣st​)At​]

用 log⁡\loglog 是因为对数概率具有良好的数学性质，∇θlog⁡πθ(a∣s)=∇θπθ(a∣s)πθ(a∣s)\nabla_\theta\log\pi_\theta(a|s) = \frac{\nabla_\theta\pi_\theta(a|s)} {\pi_\theta(a|s)}∇θ​logπθ​(a∣s)=πθ​(a∣s)∇θ​πθ​(a∣s)​，可以用于构造 Policy Gradient。

Clip

但这里存在一个问题，如果每次更新都让某些动作概率大幅度变化，策略可能突然发生剧烈改变，训练容易不稳定，因此 PPO 引入了 Clipped Surrogate Objective（截断）。

首先定义：

rt(θ)=πθ(at∣st)πθold(at∣st)r_t(\theta)= \frac{ \pi_\theta(a_t|s_t) }{ \pi_{\theta_{\text{old}}}(a_t|s_t) }rt​(θ)=πθold​​(at​∣st​)πθ​(at​∣st​)​

这个比例衡量当前新策略对这个动作的概率，相比采集经验时的旧策略发生了多大变化。

接下来定义：

LCLIP(θ)=Et[min⁡(rt(θ),clip⁡(rt(θ),1−ϵ,1+ϵ)⏟将概率比例限制在一定范围内)×At]L^\text{CLIP}(\theta)= \mathbb E_t \left[ \textcolor{red}{\min \left( r_t(\theta), \underbrace{ \operatorname{clip} (r_t(\theta),1-\epsilon,1+\epsilon) }_\text{将概率比例限制在一定范围内} \right)} \times A_t \right]LCLIP(θ)=Et​​min​rt​(θ),将概率比例限制在一定范围内clip(rt​(θ),1−ϵ,1+ϵ)​​​×At​​

其中，

clip⁡(r,1−ϵ,1+ϵ)={1+ϵ,if 1+ϵ<rr,if 1−ϵ≤r≤1+ϵ1−ϵ,if r<1−ϵ\operatorname{clip}(r,1-\epsilon,1+\epsilon)= \begin{cases} 1+\epsilon, & \text{if }\quad 1+\epsilon < r \\ r, & \text{if } \quad1-\epsilon \le r \le 1+\epsilon\\ 1-\epsilon, & \text{if }\quad r < 1-\epsilon \end{cases}clip(r,1−ϵ,1+ϵ)=⎩⎨⎧​1+ϵ,r,1−ϵ,​if 1+ϵ<rif 1−ϵ≤r≤1+ϵif r<1−ϵ​

Critic 的 Loss

我们可以利用 GAE 得到 Return Target：

Rttarget=At+Vϕ(st){ R_t^\text{target}=A_t+V_\phi(s_t) }Rttarget​=At​+Vϕ​(st​)

然后让 Critic 的预测值接近这个目标：

LVF(ϕ)=Et[(Vϕ(st)−Rttarget)2]{ L^{VF}(\phi)= \mathbb E_t \left[ (V_\phi(s_t)-R_t^\text{target})^2 \right] }LVF(ϕ)=Et​[(Vϕ​(st​)−Rttarget​)2]

这就是 Value Loss。

Entropy Bonus

Entropy Bonus（熵奖励）是强化学习和 LLM 强化学习微调常见的一种正则化机制。

如果 Actor 发现某个动作目前表现很好，可能迅速把它的概率提高到 99%，这样策略就会变得非常确定，探索能力下降。因此 PPO 通常会加入 Entropy Bonus。

策略熵衡量策略概率分布的不确定性，定义为：

H(π)=−∑aπ(a∣s)log⁡π(a∣s)\mathcal H(\pi)= -\sum_a\pi(a|s)\log\pi(a|s)H(π)=−a∑​π(a∣s)logπ(a∣s)

PPO 希望在优化动作价值的同时，保留适当的探索能力。

On Policy 训练

PPO 算法的整体 Loss 通常写成：

L=−LCLIP+cvLVF−ceH(π)L= -L^\text{CLIP} +c_vL^{VF} -c_e\mathcal H(\pi)L=−LCLIP+cv​LVF−ce​H(π)

这里采用最小化 Loss 的形式：

  • −LCLIP-L^\text{CLIP}−LCLIP：最大化策略目标。
  • cvLVFc_vL^{VF}cv​LVF：降低 Critic 的预测误差。
  • −ceH-c_e\mathcal H−ce​H：鼓励策略保持一定熵。

那么训练过程大概就可以写成：

  1. 使用当前策略采样，Actor 根据当前状态输出动作概率，随机选择动作。
  2. 收集经验，保存 State、Action、Reward、旧策略概率、Value。
  3. 计算 GAE，利用 Reward 和 Critic 的预测计算 Advantage。
  4. 更新 Actor，利用 PPO Clipped Objective 更新策略网络。
  5. 更新 Critic，利用 Value Loss 更新价值网络。
  6. 重复优化，对刚刚收集的 Batch 进行多个 Epoch 的优化。
  7. 重新采样，使用更新后的策略与环境交互，收集新经验。

PPO 主要使用当前策略产生的数据来更新当前策略，所以叫做 On-Policy 的算法。例如：

  • 当前策略是 πθ1\pi_{\theta_1}πθ1​​。
  • 用它收集一批数据。
  • 使用这批数据更新得到 πθ2\pi_{\theta_2}πθ2​​。
  • 再用新策略收集下一批数据。

PPO 会对同一批数据做多个 Epoch 的优化，但 Clip 限制了策略相对旧策略的变化。
